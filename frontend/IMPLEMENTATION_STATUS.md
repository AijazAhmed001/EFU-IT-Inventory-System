# EFU IT Hardware Inventory Frontend

React + TypeScript + Vite + Tailwind CSS frontend for the EFU inventory application.

Implemented modules include:
- Responsive login screen with password visibility, validation and loading state
- Dashboard with statistics, charts, activity and quick actions
- 14 master setup screens
- New Asset workflow
- Asset Allocation, Revocation and Expiration workflows
- Asset History / Reports
- Profile, Notifications and Settings
- Responsive sidebar/top navigation and mobile menu behavior
- Functional login/logout navigation

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
